# PROJ-EXT-2SEM
Projeto extensionista do 2° semestre da faculdade

Sistema de programação em C# (WinForms/WPF) com integração a banco de dados MySQL para automatizar os agendamentos de uma barbearia local, que antes eram feitos manualmente, com funcionalidades para cadastrar clientes, horários e serviços de forma simples e eficiente.
